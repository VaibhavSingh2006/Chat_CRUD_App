# 💬 Chat CRUD App

A full-stack **Chat CRUD Application** built using **Node.js, Express, MongoDB, and EJS**.  
The app allows users to create, view, edit, and delete chat messages with a clean, premium UI.

---

## 🚀 Features

- 📩 Create new chat messages
- 📃 View all chats
- ✏️ Edit existing messages
- 🗑️ Delete messages
- 🎨 Premium UI with cards and smooth button interactions
- 🧩 RESTful routing
- 🗃 MongoDB database integration

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS  
- **Database:** MongoDB, Mongoose  
- **Tools:** Git, GitHub, VS Code
